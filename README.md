# Monkey-Exporter
Browser tool that converts a WeebCentral subscription library CSV into a MyAnimeList manga import XML.

Only Tested on Windows 11

Instructions
1. Download the "DOWNLOAD THIS" code
2. Open the the file in Notepad
3. In notepad click "File" the top left corner then click "Save as"
4. Change "Text documents (*.txt)" to "All files"
5. Make sure the "Encoding:" in the bottom right is set to UTF-8
6. Change the file name to something easy then add ".html"
7. Then open the file you just named with the browser of your choice
8. Then open a Weeb Central tab and go to your subscriptions
9. At the the bottom of subscriptions under "Home Contact Privacy FAQ" there will be something that says "Export"
10. Click "Export" and confirm it
11. Go back to the file you named and click "Choose File" and click the file you've just exported form Weeb Central
12. Click "Convert" and wait until it's done
13. It will automatically make a XML file or you just click "Download XML"
14. Go to this page https://myanimelist.net/import.php
15. Click "Choose import type" and change it to "MyAnimeList Import"
16. Go to the box that says "Choose File"
17. Import the new XML file you created
18. Now everything should work!
